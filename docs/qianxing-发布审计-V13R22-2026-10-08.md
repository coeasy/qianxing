### 第 2 轮 · 孤儿逻辑与死配置键（1 颗，已修：`#222`）

**命中**：`tools/check_architecture.py` 的 `TEST_PATH` 只认目录式 `src/tests/`（含 `tests/mod.rs`）与 `_tests.rs`，**不认单文件式 `src/tests.rs`**。V12 R2 为绕开行数棘轮把八个 crate 的库内用例搬成了后者（`#[cfg(test)] mod tests;` 挂进来），于是「唯一读者写在 `src/tests.rs` 里」的 `pub` 项被当成有生产读者——**零读者判据在它们面前是瞎的**；同一过滤器还罩着 `PUBLIC_ENTRY_FAMILIES` 与枚举变体生产者两条判据。

**修法**：

1. `TEST_PATH` 补 `(?:^|/)tests\.rs$`（两种形态定成一个口径）。
2. 放宽后放出的 **8 条零读者**逐条进 `PUBLIC_SURFACE_ALLOWLIST` 并写明理由（共同形状：生产走 JSON 入口 `BarFrame::from_json` / `apply_corporate_actions_json`，这些类型化程序化入口只有库内用例读者）：

   | 条目 | 处置理由 |
   |---|---|
   | `qx-protocol::to_wire_json` / `from_wire_json` | 跨语言 wire 契约（文档明写「供 Rust/Python/其他 serde 实现使用」） |
   | `qx-datastruct::from_view` | DataView→BarFrame 程序化装配入口 |
   | `qx-datastruct::close_at` | 具名访问器（用例断言帧内容） |
   | `qx-datastruct::select_time_with_manifest` / `resample_with_manifest` | 变换清单链，Python 桥镜像实现 |
   | `qx-xingban::corporate_actions_from_data` | 数据层→规则事件转换入口（生产走 `apply_corporate_actions_json`） |
   | `qx-xingban::corporate_action_supported_by_ledger` | 账本支持度查询（对 Suspension/CapitalChange 回 false） |

3. **门禁牙齿**（1 颗，住在 `zero_reference_public_surface_check`）：`TEST_PATH` 必须同时认得目录式与单文件式，且不得把 `contest.rs`/`attestation.rs` 这类含 test 词干的生产文件误判。`GATE_CHECK_FLOOR` **697 → 698**。

**反向变异已实测**：把 `TEST_PATH` 改回旧写法 → 门禁当场红 **2 条**（新牙齿 + 允许清单过期 8 条）；还原后复绿 **754**。

**与立案（V13 R2 第十六遍）记的 10 条对账**：实测 8 条，差额两条已销案——`qx-protocol::to_qifi` 在 `crates/qx-cli/src/ecosystem_smoke.rs:208` 长出生产读者；`qx-runtime::to_json_for` 已改成 `#[cfg(test)] pub(crate) fn` 并搬到 `crates/qx-runtime/src/strategy_contract/contract.rs`（被 `_strip_cfg_test_items` 整项剥离）。

## 4. 环境注意事项（写给下一位跑测试的人）

本沙箱里 `%TEMP%` 对**被测子进程**不可写：`cargo test -p qx-cli` 会有一片 `os error 5`（拒绝访问）**假失败**（实测 70 条，全部停在 `crates/qx-cli/src/tests/mod.rs:54` 的 `create_dir_all`）。**收尾跑测试必须先设 `TEMP`**：

```bash
export TEMP="$PWD/.tmp-audit/tmp" TMP="$PWD/.tmp-audit/tmp"
export QX_PYTHON="$PWD/python/.venv/Scripts/python.exe"
```

否则会把环境问题误读成回归。
