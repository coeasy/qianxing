# 牵星容量与资源画像（2026-10-23）

本文把目前可复核的端到端测量汇总到同一入口，供开发机规划和后续容量测试设计使用。各行仍是特定负载下的实测值，不能当作所有账户、数据源或生产部署的最低配置。

## 测量环境

证据主要来自 Windows 工作站：AMD Ryzen 7 8700G，8 个物理核、16 个逻辑核、可见物理内存 61.4 GiB。测量分多次执行，二进制及源码指纹随每份原始证据保留；并非全部由同一 Release 构建产生，也不构成已发布版本的性能承诺。

## 画像边界与未测 profile

`maturity/targets.yaml` 登记的九档完整产品 profile 仍全部为 `unmeasured / unavailable`：A 股 Research、A 股 Paper、国内期货、国内期权、全球股票 Paper、FX Paper、Crypto Paper、Crypto Testnet 与 Multi-venue Arbitrage。上表不会把任何一档翻转为 `measured`。

目前缺少完整产品链组合负载、真实供应商数据质量与修订样本、长时间稳定性、分配次数、稳定内存上限、Paper/Testnet 任务恢复、完整期货/期权规则覆盖及跨账户服务并发证据。因此无法据此给出通用的最低 CPU、内存、磁盘或生产并发承诺。容量验收要在目标 profile、数据跨度、策略槽数、费用/撮合规则和部署硬件固定后重新测量。

真实 Binance Testnet / OKX Demo 私有账户及下单恢复验收另受凭据和网络条件约束；匿名行情探测与本地合成容量负载均不能替代该验收，`sandbox_tested` 保持 `false`。
