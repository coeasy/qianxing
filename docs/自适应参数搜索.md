# 自适应参数搜索

Bar 策略实验可在有限离散参数网格或有界整数参数范围上使用固定种子的随机搜索、TPE、核密度 TPE 或收益/回撤 Pareto TPE。未设置 `search` 时保留现有完整参数网格行为。搜索计划随实验规格一起参与指纹，结果中的 `search.trials` 记录每个候选参数、提议算法和训练分数。

```python
from qianxing import (
    BacktestExecutionCostRules,
    BacktestSpec,
    BuiltinStrategySpec,
    ExecutionCostSensitivityScenario,
    ExperimentParameterRange,
    ExperimentParameterSpace,
    ExperimentSearchPlan,
    ExperimentSplitPlan,
    RunExperimentSpec,
    run_experiment,
)

spec = RunExperimentSpec(
    experiment_id="momentum-tpe-2026-01",
    base=BacktestSpec(
        run_id="momentum-tpe-base",
        instrument="BTCUSDT.BINANCE",
        bars_path="data/bars.json",
        settlement_currency="USDT",
        initial_cash_raw=100_000_000_000_000,
        output_dir="runs",
        strategy=BuiltinStrategySpec(kind="momentum", strategy_id="momentum"),
    ),
    parameter_space=(ExperimentParameterSpace("period", (3, 5, 8, 13, 21, 34)),),
    split_plan=ExperimentSplitPlan(
        train_bars=500, test_bars=100, walk_forward=True, step_bars=100
    ),
    search=ExperimentSearchPlan(
        algorithm="tpe", seed=2026, budget=6, max_training_drawdown_bps=1800,
        fold_local_search=True
    ),
    cost_sensitivity=(
        ExecutionCostSensitivityScenario(
            name="higher-fees",
            execution_cost_rules=BacktestExecutionCostRules(
                name="stress", maker_bp=4, taker_bp=10
            ),
            fill_model="next_bar_open",
        ),
    ),
)
result = run_experiment(spec)
print(result.search)
print(result.out_of_sample)
```

## 搜索规则

- `random` 使用固定种子、无放回地抽取网格候选。
- `tpe` 先进行四次随机启动；之后以首个训练窗分数排序，把前 20% 作为较优组，用带 Laplace 平滑的分类密度比从剩余组合中提议下一个候选。参数取值是离散分类项，不做连续 KDE。
- `tpe_kde` 使用同样的训练窗排序和四次随机启动，在已验证参数网格的排序坐标上使用高斯 Parzen 核估计好/坏候选密度，按密度比挑选未运行候选。带宽按当前观测的位置方差和样本数通过 Silverman 规则确定，随后限制在半档位到半个网格宽之间；每个核在有限网格边界内归一化，并加均匀伪计数维持未观测位置的探索概率。它只用档位顺序，不进行可能溢出的 `i128` 相减；密度核是连续函数，但候选仍限于用户声明的有限网格，因此不等于连续参数域搜索。
- `search.continuous_parameter_space` 可声明 `name / min / max / step` 整数范围。候选按 `min + k * step <= max` 生成；`min` 必须非负、`max > min`、`step > 0`，每个维度最多 `2^53` 个可取值以保持序数坐标精确。该模式必须把顶层 `parameter_space` 设为空，且不能与 `strategy_kinds` 混用；字段名、策略适用性及端点类型仍按同一内置策略参数表校验。多个范围的组合空间可以很大，但每次实验最多执行 256 个候选。
- 参数维度除了信号周期/阈值和 `quantity_raw`，也支持现有定点 sizing 字段 `target_notional_raw`、`target_available_margin_bps`、`target_volatility_bps`、`target_kelly_fraction_bps`，离散网格与步进整数范围均可使用。名义金额必须大于 0；三个基点参数必须在 `1..=10000`。一轮只能搜索一种 sizing 参数，且 sizing 搜索不能与 `quantity_raw` 搜索混用；sizing 模式仍按 `BuiltinStrategySpec` 的互斥和运行约束校验。浮点金额没有进入搜索参数，避免绕过引擎的定点单位。
- 连续整数范围的随机启动同样固定为四次（`random` 除外）。后续 TPE 从训练分数前 20% 的观测中心采样高斯 Parzen 候选，再用好/坏密度比选取；普通 `tpe` 使用固定 15% 域宽，`tpe_kde` 根据观测方差和样本数自适应带宽（限制在 5% 到 50% 域宽），边界使用镜像核。每个候选会映射回对应的步进整数，拒绝重复值，并以 `*_continuous` 提议名称记录。`pareto_tpe` 先按训练收益/最大回撤的 Pareto 前沿分层，再在较优组附近提议。连续域的范围、seed、budget 和提议轨迹都参与规格身份及检查点重放。
- `pareto_tpe` 同样先进行四次随机启动；随后只用首个训练窗收益与最大回撤进行非支配分层，按前沿层级优先、收益降序、回撤升序形成确定性序列，并以排序前 20% 构造分类 TPE 提议分布。启用分段稳健性目标时，收益维度使用训练子窗最差收益，回撤维度仍使用完整训练窗最大回撤。结果同时记录每个候选的完整训练收益、分段稳健性分数、训练最大回撤及目标标记。它不读取测试窗，也不把全样本 drawdown 用作选参目标。
- 搜索预算必须大于零且不超过离散网格大小或连续范围组合的可取值数量，并受 256 候选硬上限约束。TPE 预算至少为 5。
- 可选 `max_training_drawdown_bps` 是硬风险预算（0..=10000 基点），基于首个训练窗最大回撤。设置后 TPE/Pareto TPE 只把满足预算的训练观测用于后续提议；成本敏感性只选择满足预算的候选；每折 OOS 选参也按该折训练窗回撤先过滤。若没有合格候选，搜索仍可继续探索，但成本压力测试或该折 OOS 会明确失败，不会放宽预算。搜索和折报告均回显预算。
- 搜索必须配置 `split_plan`，且只搜索参数维度；不能同时启用 `strategy_kinds`。
- 默认候选回测产物包含完整输入区间，但搜索器只读取首个训练窗的权益分数；OOS 报告逐折从该候选集合按本折训练窗选参。显式启用 `fold_local_search` 后，每折从训练起点到测试终点生成独立 BarFrame，使用按折派生的种子和全新策略实例重新执行预算内候选；TPE/Pareto TPE 每次提议只读本折已完成候选的训练收益与回撤，选中后才读取该折测试窗收益。每折轨迹、候选产物及选中 RunManifest 写入 `search.fold_searches`。
- `purge_bars` 可在训练窗和测试窗之间留出未参与评分的 Bar；折报告会标出 `purge_range`。`embargo_bars` 可在走查折的测试窗之间留出冷却区间，要求 `step_bars >= test_bars + embargo_bars`，并在折报告中标出 `embargo_range`。两个字段默认 0，旧规格保持原有序列化和指纹。
- 搜索报告附带参数邻域摘要：先从符合训练回撤硬预算的成功候选中，按当前训练选参分数选中心，再统计仅一个参数维度变化、且序数档位距离不超过 `search.neighborhood_radius` 的候选。若没有任何候选符合预算，仍以最高分候选作为诊断中心，并明确报告超预算或证据缺失。半径默认 1，允许 1..=8；离散网格按排序后的档位计距，步进整数范围按范围步长计距。报告给出理论邻居数、预算实际覆盖数、成功/失败数及邻居训练收益均值/范围；未搜索到的邻居明确表现为覆盖缺口，不视为通过。配置 `max_training_drawdown_bps` 时，同一训练预算会用于邻域判级，报告中心和邻居最大回撤、超预算邻居数及缺失回撤数据的邻居数；超预算或无法核验时不会标为 `stable_positive`。全局搜索和每个 fold-local 搜索都提供该摘要；摘要只读各自训练窗分数，不访问测试窗。半径只扩大稳定性检查范围，不自动扩充候选预算或制造未执行的邻居结果。
- 可选 `robustness_subwindows`（2..=8）把每个训练区间等分为相邻、端点重叠的连续子窗；要求训练 Bar 至少为子窗数加一。每个候选照常报告完整训练收益，另报告子窗收益的最小值。启用后该最小值驱动 TPE/Pareto TPE 提议、全局候选排名、成本情景选参，以及全局 OOS 每折和 fold-local 的训练内选参；最大回撤约束仍按完整训练区间执行。每折从自己的训练区间重新切分子窗，测试和 purge Bar 不进入评分。邻域摘要中的收益统计同步采用当前选参分数。默认不设置时，旧版选参顺序、序列化和规格指纹不变。
- 可选 `minimum_training_robustness_score_bps` 是训练稳健收益的硬下限，要求同时配置 `robustness_subwindows`。全局 OOS 和每个 fold-local 搜索仅选择子窗最差收益达到该下限的候选；成本敏感性也只从达标候选选择基线。若某折没有候选达标，该折不会产生选中参数或 OOS 分数；完整搜索轨迹仍保留，便于定位门槛过严还是策略表现不足。该下限在规格与结果报告中回显，旧规格省略时保持旧序列化与选参行为。
- 邻域报告还提供训练窗 `assessment`：`incomplete_neighborhood` 表示半径范围内尚有邻居未搜索，`no_neighbors` 表示网格在该半径内没有邻居，`no_successful_neighbors` 表示完整搜索后没有成功邻居；中心收益非正时为 `no_positive_training_edge`；中心收益为正且邻居全部成功、收益均为正时为 `stable_positive`。配置回撤预算后，`drawdown_budget_exceeded` 表示中心或至少一个邻居超预算，`drawdown_budget_unverified` 表示成功邻居缺少回撤证据；其余不满足稳定条件的中心为 `fragile_positive`。该规则刻画训练窗参数邻域的稳定度，不等同于跨市场/跨时期稳健性或样本外保证。旧版结果没有这些字段时 Python/Rust 读取为未评估，schema v1 保持向后兼容。
- 步进整数范围的邻域按每个参数的 ±N 档生成，不依赖枚举整个组合空间。半径最大 8；预算没有覆盖到的邻居标为 `incomplete_neighborhood`；失败邻居计入已覆盖但不计入成功分数。浮点参数域仍未支持，因此没有对连续浮点邻域作稳定性声明。
- 可选 `cost_sensitivity` 会从训练窗选出的候选出发，针对每个声明的通用 `BacktestExecutionCostRules` 或 A 股 `ashare_rules`，连同 `fill_model` 再完整运行一次标准回测；结果附上情景回测产物、相对原始成本回测的收益/回撤变化和被压力测试的候选序号。每个实验最多 16 个情景，情景运行仍经过原有费用、延迟、撮合、账本和回放链路，不会对汇总收益做比例缩放。每个情景还可设 `max_training_return_degradation_bps`（0..=10000）；设定后，仅当压力运行成功、每个训练折都有可计算比较且每折收益退化均在阈值内，`cost_robustness_passed` 才为 true。搜索报告汇总已配置的门，未设置时不输出门控状态。
- 显式启用 `fold_local_search` 时，每折还会用该折训练窗选出的参数重跑同一组成本情景；`search.fold_searches[].cost_sensitivity` 保存逐折产物及相对该折基准在测试窗上的收益/最大回撤变化。全局 `cost_sensitivity` 仍独立报告全局搜索路径的结果，两种结果不可混读。
- `one_tick_slippage` 情景需要基准回测显式提供 `market_spec.price_tick`；示例仅演示通用费率压力情景。A 股规则情景已在 `ashare_cost_sensitivity_replays_with_declared_rules_and_real_fills` 中用非零成交、AShareFee 费用模型及收益下降完成行为验证。
- 取消在候选边界及折内候选边界检查；部分搜索取消时不发布完整实验结果。相同规格、数据和种子得到相同的候选提议次序。全局候选、顶层成本情景与所有折内候选/压力情景合计最多执行 4096 次回测，超限在运行前拒绝。全局 `search.trials` 与顶层成本压力情景仍基于首训练窗候选；`out_of_sample` 在折内模式下只使用 `fold_searches` 中的独立候选和折内测试收益。
- 实验报告写入完整输入 BarFrame 指纹。复用同一 `experiment_id` 的既有结果前会重算输入指纹；旧报告则从成功候选产物恢复该指纹，无法确认身份或数据已变化时拒绝返回旧结论。折内与全局成功搜索候选在训练指标确定后逐个写检查点；成功的全局/逐折成本情景也会写检查点。重启时先重放相同搜索提议，再核对规格/数据指纹、折号、选中序号与参数、情景序号、标准回测产物和完整产物字节，只有全部匹配才复用。若既有实验报告包含失败候选或成本情景，同规格再次提交时会重试没有成功检查点的项目并复用已复核成功项；失败项不保存为成功检查点。最终报告发布前不会声称整个实验已完成。

## 当前边界

`tpe` 与 `tpe_kde` 默认使用完整训练窗收益；设置 `robustness_subwindows` 后改用训练子窗最差收益。`pareto_tpe` 提供当前选参收益与训练窗最大回撤两个目标的 Pareto 前沿提议。离散网格与有界步进整数范围都可进行自适应提议；当前没有连续浮点参数。邻域自动判定覆盖可配置半径 1..=8 的单维参数档位，并按训练选参分数及可选最大回撤预算分级；更远半径的候选覆盖取决于搜索预算，缺失候选仍报告为不完整。成本情景可分别设置选中候选训练窗阈值和邻域训练窗阈值；后者会逐个复跑配置半径内已搜索的一维邻居，要求理论邻居全部被搜索、每个邻居基线与压力运行成功且每个训练折都未超限。未覆盖邻居会判失败，搜索预算不会自动扩张。跨折 OOS 报告会汇总正收益折数、最差训练收益、最差训练回撤和最差 OOS 收益；这些是事后诊断，不参与跨折候选提议或选择。成本情景要求搜索规格和 OOS 切分；每个情景必须显式提供通用或 A 股成本规则之一，不会默默跳过成本。全局和折内成功候选及成功成本情景可按检查点安全续跑；失败项会在下次同规格执行时重试并复用经复核成功项。完整区间的传统比较排名仍会作为对照字段出现；评价泛化能力时应读 `out_of_sample`，不要用全样本收益排名替代 OOS。

### 训练窗回撤早停

可在 `search.early_pruning` 设置 `min_training_bars`，并同时声明 `max_training_drawdown_bps`。门槛必须落在 `2..=train_bars` 内。候选至少完成指定数量的训练 Bar 后，回撤一旦超过硬预算就立即停止；监控只覆盖首折训练窗，绝不触碰 purge、测试窗或后续走查折。回撤按逐 Bar 的运行权益峰值计算，后续新高不能稀释此前回撤。

被提前停止的候选保留处理 Bar 数、已观察最大回撤和预算，`pruned_candidates` 单独计数；它没有 `BacktestOutcome`、错误或半成品成功产物。同规格恢复会把剪枝视为已完成的终止状态，而重试真正失败的候选。逐折独立搜索使用各折自己的训练窗边界。真实 Bar 引擎和 `run-experiment` 集成场景已覆盖训练边界、超预算记录和不发布半成品产物。

2026-10-23 Release 容量复测已补上：`benchmarks/run_adaptive_search_capacity.py` 支持 `--early-pruning-drawdown-bps` 与 `--early-pruning-min-training-bars`，并将启用剪枝的 workload 与相同 seed/候选的完整基线交错运行。当前证据 `maturity/evidence/adaptive-search-pruning-capacity-2026-10-23.json` 覆盖 8k/64k Bar × 8/32 候选、每格两次重复，记录剪枝候选数、节省 Bar 数、剪枝轨迹、提议轨迹、进程树 RSS 与配对耗时。64k × 32 候选在 1 bp 合成回撤压力下 P50 为 3.593 秒，对照完整基线 29.598 秒，省下 1,332,440 个训练 Bar；所有候选都被剪枝，所以该值只说明早停成本上限，不代表选参质量或泛化表现。

### 费用邻域门容量样本

`benchmarks/run_cost_neighborhood_capacity.py` 使用 Release `app run-experiment` 测量有限网格 TPE-KDE、所选候选的费用压力回测，以及半径 1 内全部单维邻居的费用压力回测。2026-10-23 样本覆盖 8k/64k Bar × 8 候选，每档重复两次；每次包含 8 个候选基线、1 个中心压力运行和 2 个邻居压力运行，全部理论邻居覆盖、基线与压力运行均成功，提议/结果哈希跨重复稳定。8k P50/P95 为 5.702/6.628 秒，进程树 RSS 峰值 28.4 MiB；64k 为 21.861/31.480 秒、192.1 MiB。原始证据 [adaptive-search-cost-neighborhood-capacity-2026-10-23.json](../maturity/evidence/adaptive-search-cost-neighborhood-capacity-2026-10-23.json) 绑定当前 Release 与源码/脚本指纹。该测量不覆盖浮点参数空间、并行搜索或完整产品 profile。

### 参数邻域费用门控

在每个 `ExecutionCostSensitivityScenario` 上设置 `max_neighborhood_training_return_degradation_bps`（0..=10000），会对训练窗选中的中心候选的可配置半径内每个已搜索的一维邻居，按该成本情景重跑一次完整回测。邻居训练窗收益退化须在阈值内；中心候选由 `max_training_return_degradation_bps` 独立验收。门控仅使用训练折，逐折搜索会对每个折分别计算。

只有理论邻居至少一个、所有理论邻居都已搜索、邻居基线与压力回测全部成功且每个训练折都通过，`neighborhood_cost_robustness.passed` 才为 true；理论覆盖不足、基线剪枝/失败或成本压力失败都会判 false，并返回半径、理论/已测覆盖数及逐邻居参数、产物与折差值。成功的邻居压力回测使用与中心候选相同的身份校验检查点续跑。邻域压力回测计入搜索资源上限；预算不足时门控失败，不会自行增加候选数。搜索总报告提供独立的 `neighborhood_cost_robustness_passed`，Web Console 可查看门控覆盖与逐邻居结果。

可运行的验收包括 `cargo test -p qx-app --lib experiment_search::tests`、`cargo test -p qx-app --test experiment_split`、`cargo test -p qx-app --test experiment_split purged_and_embargoed_intervals_are_present_in_the_saved_experiment_report`，以及 Rust SDK 和 Python SDK 的实验用例。Python 原生扩展需从当前源码构建，否则会因加载旧二进制而不认识新增字段。

### 稳健选参容量样本

`benchmarks/run_adaptive_search_capacity.py --robustness-subwindows 4` 通过正式 Release `app run-experiment` 路径，测量四段训练子窗最差收益驱动的 TPE-KDE。2026-10-23 的合成 crypto-spot SMA 样本覆盖 8k/64k Bar、8/32 候选、每格两次重复；四格候选均成功，提议轨迹和回测结果哈希重复一致。P50 分别为 1.337/3.508 秒（8k、8/32 候选）和 6.330/23.932 秒（64k、8/32 候选），进程树 RSS 峰值分别约 30.9/31.4 MiB 和 197.9/197.2 MiB。完整原始记录见 `maturity/evidence/robust-continuous-adaptive-search-capacity-2026-10-23.json`。此项只测单进程步进整数 SMA 负载，不覆盖浮点搜索、早停、并行候选或完整产品 profile；九档产品画像仍按目标台账保持未测。
