# Qianxing v0.0.1 Release

## Overview

Qianxing v0.0.1 is the first unified release of the Rust native quantitative trading infrastructure.

## Highlights

- Event driven kernel architecture
- Domain driven trading model
- Market data normalization pipeline
- Order lifecycle management
- Matching engine foundation
- Risk rule engine
- Event sourcing and deterministic replay
- Plugin extension framework
- Multi-language SDK boundary
- CLI runtime entrypoint

## Validation

- Architecture boundary checks
- End-to-end trading pipeline validation
- Deterministic replay verification
- Performance benchmark gate

## Release Scope

This release establishes the core infrastructure foundation. Broker adapters, advanced strategies, and extended SDK integrations will continue evolving in future versions.
