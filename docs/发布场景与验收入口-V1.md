# 牵星发布场景与验收入口 V1

更新日期：2026-10-24

本文将 `qx-cli init --profile` 的项目模板收敛到三个面向用户的首发场景。这里的 onboarding profile 只决定生成哪些配置和样例文件，不替代运行时的 `single_node` / `distributed` 部署拓扑，也不代表交易所或策略已完成验收。

## 场景一：research-local

适合本机研究、文件行情回测和策略参数实验。无需交易所账号或密钥。

```powershell
qx-cli init ./research-local/qianxing.runtime.json --profile research-local
qx-cli doctor ./research-local/qianxing.runtime.json
qx-cli config validate ./research-local/qianxing.runtime.json
```

项目生成在 `research-local/`，回测产物统一写入项目的数据目录 `data/qianxing/runs/`；初始化输出和生成的 `README.qianxing.md` 会给出这份配置实际可运行的回测命令。更换策略文件或数据集后，应重新运行 `doctor`、`config validate`，再执行回测。策略文件搜索与离线报告入口见根目录 README 的 Python 用户策略章节。

## 场景二：crypto-paper

适合验证行情、策略、风控、订单、Paper 撮合和账本链路，不连接交易所、不使用真实账户余额。

```powershell
qx-cli init .\crypto-paper\qianxing.runtime.json --profile crypto-paper
qx-cli doctor .\crypto-paper\qianxing.runtime.json
qx-cli config validate .\crypto-paper\qianxing.runtime.json
qx-cli paper-check --json .\crypto-paper\qianxing.runtime.json
```

Paper 事实和报告写入配置声明的 `data/qianxing-paper/` 及 `paper-check` 数据目录。Paper 报告必须按模拟撮合假设解读；它不能证明 sandbox 或生产交易所的连接、精度、订单状态和恢复行为。

## 场景三：crypto-sandbox-acceptance

适合使用自己的交易所 demo/testnet 账户，逐条验收公共行情、账户读取、下单、订单查询、撤单、成交、对账与重启恢复。模板默认引用 OKX CCXT 配置并开启 `sandbox: true`，不包含密钥，也不会自动发送订单。开始前应登录交易所官方入口创建 demo/testnet API Key，并只授予验收所需权限。

```powershell
qx-cli init .\crypto-sandbox\qianxing.runtime.json --profile crypto-sandbox-acceptance
qx-cli doctor .\crypto-sandbox\qianxing.runtime.json
qx-cli runtime-check .\crypto-sandbox\qianxing.runtime.json
```

默认凭据名称为 `QX_CCXT_OKX_API_KEY`、`QX_CCXT_OKX_SECRET`、`QX_CCXT_OKX_PASSWORD`；在当前终端或密钥管理器中设置变量名对应的秘密值。修改 endpoint、产品和账户模式后再次运行 `doctor` 与 `runtime-check`。模板只声明 sandbox 连接；真正的下单验收必须由操作者逐条执行并核对交易所 demo 账户中的订单、成交、费用、余额和重启后的对账结果。`live-check` 是 production 配置门禁，不是 sandbox 验收器。验收记录不得写入密钥明文，未实测的能力仍标记为未验收。

生成项目中的实时运行数据写入配置声明的 `data/qianxing-ccxt/`。凭据缺失、API 权限不足、环境切错或 sandbox endpoint 不匹配时，停止在配置/连通预检阶段，修正配置后重跑；不得把 demo key 用于 production。

## 支持边界

| 场景 | 入口模板 | 是否需要外部账号 | 首要验收 | 不代表 |
|---|---|---:|---|---|
| `research-local` | `qianxing.runtime.strategy-backtest.example.json` | 否 | 文件策略回测与研究产物 | 策略未来数据安全或收益有效 |
| `crypto-paper` | `qianxing.runtime.paper-strategy.example.json` | 否 | Paper 订单至账本链路 | 交易所连接或真实成交 |
| `crypto-sandbox-acceptance` | `qianxing.runtime.ccxt.example.json` | 是，使用交易所 demo/testnet | 交易所逐项验收记录 | production 上线认证 |

状态目录可以通过 `qx-cli doctor --capabilities` 离线查看；该目录说明代码声明和证据档位，当前机器/凭据的就绪情况仍由对应 runtime 预检与独立 sandbox 验收决定。
